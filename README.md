# Как сверить натальные карты из двух калькуляторов

Два калькулятора могут показать одинаковые градусы планет и при этом поместить их в разные дома. Если расходятся и градусы, сначала сравните входные данные и настройки зодиака. Ниже есть контрольный расчёт, в котором меняется только один параметр за раз.

## Контрольный пример

Возьмём учебные данные **4 июля 1995 года, 14:30, Берлин** (52,52° с. ш., 13,405° в. д.). Сравниваем тропические геоцентрические долготы. Для Берлина на эту дату местное время соответствует **12:30 UTC**. В третьем варианте намеренно подставлен фиксированный UTC+1 вместо летнего UTC+2.

| Вариант | UTC | Солнце | Луна | Асцендент | Начало II дома | Начало X дома |
|---|---|---:|---:|---:|---:|---:|
| Плацидус, исторический пояс | 12:30 | 102,08° | 175,96° | 202,89° | 229,20° | 120,74° |
| Целые знаки, исторический пояс | 12:30 | 102,08° | 175,96° | 202,89° | 210,00° | 90,00° |
| Плацидус, фиксированный UTC+1 | 13:30 | 102,12° | 176,51° | 213,27° | 240,88° | 135,54° |

В первых двух строках положения планет и асцендент совпадают, а начала домов расходятся. В третьей строке меняется сам момент расчёта. Асцендент пересекает границу Весов и Скорпиона (210°), хотя на местных часах в обоих вариантах указано 14:30.

## Порядок проверки

1. **Сверьте исходные данные.** Сравните координаты города, местные часы и минуты и пересчёт в UTC. Проверьте, учтено ли летнее время на дату рождения.
2. **Сравните градусы Солнца и Луны.** Если значения отличаются, проверьте тропический или сидерический зодиак, а для Луны также точность времени и режим расчёта. Убедитесь, что обе программы показывают одну шкалу градусов.
3. **Сравните асцендент и начала домов.** При одинаковом асценденте различия в сетке домов часто объясняются Плацидусом, целыми знаками или другой системой домов.
4. **Проверьте вычисляемые точки и аспекты.** Для лунных узлов сравните режим «истинный» или «средний». Если градусы планет совпадают, а списки аспектов расходятся, сверьте допустимое отклонение от точного угла и набор учитываемых аспектов.

## Воспроизведение расчёта

Нужны Python 3.9+ и [pyswisseph 2.10.3.2](https://pypi.org/project/pyswisseph/2.10.3.2/). Для установки в виртуальном окружении выполните `python -m pip install pyswisseph==2.10.3.2 tzdata`.

```python
from datetime import datetime, timedelta, timezone
from zoneinfo import ZoneInfo

import swisseph as swe

local = datetime(1995, 7, 4, 14, 30, tzinfo=ZoneInfo("Europe/Berlin"))
fixed_offset = local.replace(tzinfo=timezone(timedelta(hours=1)))
scenarios = [
    ("Placidus", local, b"P"),
    ("Whole Sign", local, b"W"),
    ("Placidus, UTC+1", fixed_offset, b"P"),
]

for name, time, system in scenarios:
    utc = time.astimezone(timezone.utc)
    jd = swe.julday(utc.year, utc.month, utc.day, utc.hour + utc.minute / 60)
    cusps, angles = swe.houses(jd, 52.52, 13.405, system)
    sun = swe.calc_ut(jd, swe.SUN, swe.FLG_MOSEPH)[0][0]
    moon = swe.calc_ut(jd, swe.MOON, swe.FLG_MOSEPH)[0][0]
    values = [sun, moon, angles[0], cusps[1], cusps[9]]
    print(name, f"{utc:%H:%M} UTC", *(f"{value:.2f}°" for value in values))
```

Для практической проверки можно взять свою карту в любом калькуляторе, записать эти параметры и сравнить с [расчётом натальной карты в Aistre](https://aistre.ru/natalnaya-karta?utm_source=github&utm_medium=referral&utm_campaign=natalcard_readme_pilot&utm_content=sravnenie_kart). Наш калькулятор использует тропический зодиак и систему домов Плацидуса.

Если точное время неизвестно, сначала проверьте [какие положения можно определить по дате рождения](https://github.com/natal-card/natalnaya-karta-bez-vremeni-rozhdeniya).
